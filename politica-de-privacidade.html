TRANSPARÊNCIA E LGPD

Política de Privacidade

Última atualização: 14 de setembro de 2026.

Esta política explica, de forma simples e direta, como o site clubinhoambienteanimal.com.br trata dados ao ser visitado. Ela existe para cumprir a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD) e para que você saiba exatamente o que acontece com qualquer informação sua.

1. Quem é o responsável por este site

O site é mantido por Jorge Luiz do Nascimento Loureiro, pessoa física, à frente do Clubinho Ambiente Animal, pet shop em funcionamento desde 1996, localizado na Rua Bogari, 99, Taquara, Rio de Janeiro — RJ. Para qualquer assunto relacionado a privacidade e dados pessoais, o contato é:

  • E-mail: jorg.silvia@hotmail.com
  • WhatsApp: +55 21 99298-5489

2. Quais dados este site coleta

Este é um site estático — não tem formulário de cadastro, não tem login, não tem carrinho de compras e não guarda nada em banco de dados. Isso limita bastante o que existe para tratar:

  • Links para o WhatsApp: os botões "Consultar no WhatsApp" e similares apenas abrem uma conversa no aplicativo, com uma mensagem pré-preenchida. Qualquer dado pessoal que você decida compartilhar a partir daí (nome, telefone, endereço, dados do seu pet etc.) é tratado dentro do WhatsApp, sob a política de privacidade da própria Meta/WhatsApp — o site não recebe, não armazena e não tem acesso a essa conversa.
  • Métricas de acesso (Vercel Analytics): usamos uma ferramenta de estatísticas agregadas e anônimas para entender quantas pessoas visitam o site, quais páginas acessam e de onde vêm (ex: Google, Instagram, acesso direto). Essa ferramenta não usa cookies, não atribui um identificador único a cada visitante e não permite identificar quem você é — os números são agregados (ex: "120 visitas essa semana"), não individuais.

3. Cookies

Este site não utiliza cookies de rastreamento, publicidade ou de terceiros. Por isso não exibimos banner de cookies: não haveria nada de opcional para você aceitar ou recusar.

4. Avaliações de clientes reproduzidas no site

A seção "Avaliações" e os dados estruturados (JSON-LD) do site reproduzem avaliações públicas feitas voluntariamente por clientes no Google Perfil da Empresa do Clubinho Ambiente Animal, incluindo nome e comentário de quem optou por avaliar publicamente. A base legal para essa reprodução é o legítimo interesse (art. 7º, IX da LGPD), já que se trata de conteúdo que o próprio cliente tornou público como avaliação. Se você é cliente, deixou uma avaliação e prefere que ela não apareça neste site, é só pedir a remoção pelo e-mail de contato acima — atendemos prontamente.

5. Com quem compartilhamos dados

Não vendemos, alugamos ou compartilhamos dados pessoais com terceiros para fins comerciais ou publicitários. O site é hospedado pela Vercel Inc., empresa sediada nos Estados Unidos, responsável por servir os arquivos do site e processar as métricas de acesso agregadas mencionadas no item 2. Esse é o único terceiro envolvido na operação técnica do site.

6. Seus direitos como titular de dados

A LGPD (art. 18) garante a você, a qualquer momento e mediante solicitação pelo e-mail de contato, o direito de:

  • confirmar se tratamos algum dado seu;
  • acessar os dados que eventualmente tratamos;
  • corrigir dados incompletos, inexatos ou desatualizados;
  • solicitar anonimização, bloqueio ou eliminação de dados desnecessários ou excessivos (como uma avaliação, conforme item 4);
  • solicitar a portabilidade dos dados a outro fornecedor;
  • ser informado sobre com quem compartilhamos seus dados;
  • revogar consentimento, quando aplicável;
  • se opor a um tratamento realizado com base em legítimo interesse.

7. Segurança

O site é servido inteiramente por HTTPS (conexão criptografada), com cabeçalhos de segurança configurados no servidor (como Content-Security-Policy e HSTS) para reduzir riscos comuns de navegação. Como não há banco de dados nem formulário, não há uma base de dados de clientes armazenada no site que possa vazar.

8. Alterações a esta política

Podemos atualizar esta política sempre que o site mudar de forma relevante para a privacidade dos visitantes (por exemplo, se um dia passarmos a usar uma ferramenta de analytics diferente ou adicionarmos um formulário). A data no topo desta página sempre indica a versão mais recente.

9. Contato

Dúvidas, pedidos relacionados aos seus dados ou qualquer outro assunto de privacidade podem ser enviados para jorg.silvia@hotmail.com.
